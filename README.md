# Week 5 Assignment - Interactive Forum App


## About This Assignment

เป็นการพัฒนาเว็บแอปพลิเคชันกระดานสนทนาจำลองแบบอินเทอร์แอกทีฟ (Interactive Forum / Message Board) ที่เปิดโอกาสให้ผู้ใช้งานสามารถพิมพ์ข้อความ โพสต์ข้อความใหม่ และจัดการข้อมูลบนหน้าจอได้ทันทีแบบเรียลไทม์ โดยมุ่งเน้นการบูรณาการความรู้ด้าน:
* **HTML5 & CSS3:** การออกแบบโครงสร้างหน้าฟอรัม ตกแต่ง UI ของกล่องข้อความ ปุ่มกด (`Post`, `Clear`) และจัดวางเลย์เอาต์ให้สวยงาม ทันสมัย ใช้งานง่าย
* **JavaScript (DOM Manipulation & Event Handling):** การเขียนสคริปต์ควบคุมการทำงานฝั่งไคลเอนต์ (Client-side) เพื่อดึงค่าข้อความจากฟอร์ม ตรวจสอบเงื่อนไข และเพิ่มรายการโพสต์ใหม่เข้าสู่หน้าเว็บโดยไม่ต้องรีเฟรชหน้าจอ
* **Responsive Design:** การปรับแต่งหน้าเว็บไซต์ให้สามารถรองรับการแสดงผลบนอุปกรณ์หลากหลายขนาดได้อย่างราบรื่น

---

## Key Features & Functionality 

* **Interactive Post System:** ผู้ใช้สามารถพิมพ์ข้อความลงในช่อง Textarea แล้วกดปุ่ม `Post` (สีเขียว) เพื่อส่งข้อความให้แสดงผลบนกระดานฟอรัมได้ทันที
* **Clear Input Mechanism:** ปุ่ม `Clear` (สีแดง) สำหรับล้างข้อความในช่องพิมพ์กรณีต้องการยกเลิกหรือแก้ไขข้อความใหม่ได้อย่างรวดเร็ว
* **Dynamic Content Display:** ระบบส่วนหัวข้อ ("Welcome to the Forum") และพื้นที่แสดงข้อความสนทนาที่ถูกจัดเรียงอย่างเป็นระเบียบ อ่านง่าย และมีลำดับขั้นตอนชัดเจน

---

## Technical Stack

* **HTML5:** โครงสร้างส่วนประกอบหน้าเว็บและฟอร์มรับข้อมูล
* **CSS3:** ตกแต่งสไตล์ สีสัน ฟอนต์ และการจัดเลย์เอาต์
* **JavaScript (main.js):** จัดการเหตุการณ์ (Event Listeners) และควบคุมการทำงานแบบไดนามิก
* **GitHub Pages:** สำหรับเผยแพร่และแสดงผลเว็บไซต์ออนไลน์
